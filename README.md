# Smart Hospital Logistics Management System

This repository is for building a production-minded hospital logistics management system from zero to one, grounded in BIM-based smart operations.

## Current Artifacts

- `AGENTS.md` - AI and engineering guardrails for this project.
- `docs/00-source-review-index.md` - sanitized source-reading index from the PPT and company rules.
- `docs/01-project-rules.md` - project-level rules, safety boundaries, and engineering discipline.
- `docs/02-module-boundaries.md` - hospital logistics module boundaries and integration scope.
- `docs/03-top-level-architecture.md` - top-level architecture, technology direction, and V1 priorities.

## Source Material Policy

Internal PPTs, exported slide images, company training documents, customer data, credentials, and raw notes must not be committed to this public repository.

Only generated system code, sanitized project documents, tests, and necessary engineering configuration should be uploaded.
