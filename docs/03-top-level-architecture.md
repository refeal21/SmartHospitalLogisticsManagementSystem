# 顶层架构方案

## 架构目标

构建以 BIM 数字孪生时空底座为核心的医院后勤管理系统，实现“全域感知、告警预警、预测防控、服务闭环、质量改进、成本优化”。系统必须从第一天就具备真实业务演进能力，而不是只服务展示。

## 分层架构

1. 展现层
   - 运营驾驶舱、后勤调度台、工单中心、设备设施台账、环境监管、综合管理、BIM 空间视图。
   - 支持 PC 管理端优先，预留大屏和移动端适配。

2. 应用层
   - 基础运行、后勤服务、环境监管、综合管理四大业务应用。
   - 安全、应急、安保相关能力作为联动应用或后续扩展域。

3. 领域层
   - 空间、设备、工单、事件、人员组织、合同、质量、能耗、成本、知识库等领域模型。
   - 保留状态机、SLA、审计、权限、指标口径。

4. 集成层
   - BIM 适配器、IoT 适配器、消息适配器、医院系统适配器、第三方服务适配器。
   - 所有外部系统通过统一接口进入，内部业务不直接依赖外部协议。

5. 数据层
   - 业务数据库：工单、资产、人员、质量、合同、配置、权限。
   - 时序数据：环境、能耗、设备运行、告警历史。
   - 文档与附件：图片、报告、合同、巡检记录。
   - 分析数据：指标快照、统计报表、绩效、成本。

6. AI 能力层
   - 智能派单、故障知识推荐、告警聚合、异常趋势识别、运营报告、问答助手。
   - AI 只做辅助建议，关键处置、合同、考核、权限仍由人确认。

## 推荐技术路线

- 前端：TypeScript + React + Vite，采用信息密度高的管理系统布局。
- 后端：优先 .NET 9 / C# 12，采用整洁架构和垂直业务模块；如果后续必须快速原型，可先用 Node 轻量 API，但领域模型保持可迁移。
- 数据库：PostgreSQL 作为主业务库；时序数据预留 TimescaleDB 或独立时序库；缓存预留 Redis。
- BIM/三维：前端预留 Three.js/Cesium/平台 SDK 适配层；V1 可先用楼层平面图/空间树/构件 mock 映射。
- 测试：后端单元测试和 API 集成测试；前端组件测试和 Playwright E2E；关键流程必须有回归用例。

## V1 页面与能力优先级

1. 首页驾驶舱
   - 全院后勤态势、今日工单、告警、SLA、能耗、质量、成本、重点空间。

2. BIM 空间运营视图
   - 院区/楼栋/楼层/房间导航，设备点位、告警点位、工单点位、空间详情。

3. 工单与调度中心
   - 报修/服务请求、派单、接单、执行、验收、回访、评价、超时升级。

4. 设备设施管理
   - 台账、分类、位置、状态、维保计划、巡检记录、故障历史。

5. 环境监管中心
   - 数据采集状态、监测指标、阈值策略、预警池、报警处置、趋势分析。

6. 后勤服务管理
   - 保洁、配送、餐饮、被服、库房、太平间、病区支持等服务模块的统一入口。

7. 综合管理
   - 质量体系、合同、考核、人员、班组、外包单位、成本、运营分析。

8. 系统管理
   - 组织、角色、权限、字典、流程配置、SLA、通知策略、审计日志。

## 后端模块建议

- IdentityAccess：用户、角色、权限、组织、审计。
- SpatialTwin：院区、楼栋、楼层、房间、BIM 构件、空间标签。
- AssetFacility：设备设施、系统分类、台账、运行状态、维保计划。
- WorkOrder：报修、服务请求、派单、状态流转、SLA、回访评价。
- EnvironmentOps：监测点、指标、阈值、告警、趋势、处置策略。
- LogisticsService：保洁、配送、餐饮、被服、库房、病区支持。
- QualityCost：质量标准、合同、考核、成本、能耗、运营分析。
- IntegrationHub：BIM、IoT、消息、医院系统、第三方维保适配。
- AiAssistant：知识库、派单建议、风险分析、报告生成。

## 首批数据表前缀

- `sys_`：系统、组织、权限、字典、审计。
- `twin_`：空间、BIM、构件、点位。
- `asset_`：设备、设施、维保、巡检。
- `wo_`：工单、服务请求、流转、评价。
- `env_`：环境指标、监测点、告警、阈值。
- `svc_`：后勤服务子域。
- `qc_`：质量、合同、考核、成本、能耗。
- `int_`：外部系统映射、同步任务、集成日志。

## 关键闭环

- 感知闭环：IoT/人工上报 -> 数据采集 -> 阈值/规则 -> 告警 -> 工单 -> 处置 -> 复盘。
- 服务闭环：请求 -> 派单 -> 执行 -> 验收 -> 回访 -> 评价 -> 考核。
- 空间闭环：空间/设备/BIM 构件 -> 事件定位 -> 路径/影响分析 -> 现场处置 -> 历史沉淀。
- 质量闭环：标准 -> 过程记录 -> 结果评价 -> 问题整改 -> 绩效与合同联动。
- 成本闭环：能耗/人力/物资/合同 -> 成本归集 -> 异常分析 -> 优化建议。
