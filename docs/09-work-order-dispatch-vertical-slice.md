# 一站式工单调度纵切

## 目标

本纵切把“工单全流程管理”从功能矩阵推进到可运行业务闭环。V1 使用内存 mock 数据，不接入真实客户数据和生产系统；所有工单、点位、班组和时间均为脱敏示例。

## 来源约束

- 中科医信：报修、派单、接单、挂单、转单、完工、验收、评价、消息和调度中心颗粒度。
- PPT：一站式服务闭环、BIM 空间定位、环境监管和综合管理目标。
- 北建院：环境、医废、强电、暖通、给排水等真实系统和角色字段，作为后续工单来源与专业班组映射依据。

## 状态机

| 动作 | 允许前置状态 | 目标状态 | 业务含义 |
| --- | --- | --- | --- |
| 派工 | 新建、已升级、已转单、已挂单 | 已派工 | 调度员按 SLA、专业和班组负载指定负责班组 |
| 接单 | 已派工、已挂单、已转单 | 处理中 | 班组确认接单并进入现场处置 |
| 挂单 | 处理中 | 已挂单 | 因备件、协同或现场条件暂缓 |
| 转单 | 已派工、处理中、已挂单、已转单 | 已转单 | 需要更换或补充专业班组 |
| 完工 | 处理中、已转单 | 待验收 | 班组提交完成结果 |
| 验收 | 待验收 | 待评价 | 管理者验收通过后等待评价归档 |
| 驳回 | 待验收 | 处理中 | 管理者要求继续整改 |
| 评价 | 待评价 | 已关闭 | 服务对象评价并闭环 |
| 升级 | 非已关闭 | 已升级 | SLA 或风险触发升级 |

## API 合约

- `GET /api/operations/dispatch-board`
  - 返回工单池、班组负载、派工建议和 SLA 风险摘要。
- `GET /api/operations/work-orders/{workOrderNo}`
  - 返回工单详情、BIM 位置、来源证据、SLA 风险、允许动作和流转记录。
- `POST /api/operations/work-orders/{workOrderNo}/dispatch`
  - 请求：`teamName`、`dispatcher`、`remark`。
  - 成功返回更新后的工单详情；不存在返回 404；非法状态返回 400。
- `POST /api/operations/work-orders/{workOrderNo}/transition`
  - 请求：`action`、`operator`、`remark`、可选 `targetTeam` 和 `rating`。
  - 成功返回更新后的工单详情；不存在返回 404；非法流转返回 400。

## 验收

- 工单池按优先级和 SLA 风险排序。
- 医废负压工单能显示 BIM 点位 `BIM-LOG-F1-WASTE` 和 `SLA 风险：High`。
- 派工后状态变为“已派工”，流转记录新增“派工”。
- 接单后状态显示“处理中”，流转记录新增“接单”。
- 每个工单详情至少保留一个非 AI 来源证据。
