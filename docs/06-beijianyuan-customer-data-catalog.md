# 北建院客户数据目录（脱敏摘要）

## 资料边界

来源为本地客户调研 Excel《北建院系统及数据0531.xlsx》。本文只保留系统类别、传感器类别、位置类型、可采集字段、希望采集字段、角色和使用端等脱敏结构，不保存原始表格、现场真实点位、联系人、备注原文或任何凭据。

## 使用原则

- 该目录优先级高于竞品功能树和 PPT 架构，用于约束本项目的数据模型、菜单颗粒度、监测指标和角色权限。
- 所有物联接入先建“系统-子系统-传感器-位置-指标-角色-端”的标准目录，再做具体页面。
- V1 先用内存种子和 mock 采集值验证业务闭环，后续接入真实 IoT 时通过适配器映射。

## 对数据模型的约束

- `CustomerDataSystem` 必须保留大类、子系统、传感器、位置、可采集字段、希望采集字段、角色和使用端。
- 监测点位模型必须能关联 BIM 空间、设备资产、指标定义、阈值策略、告警事件和工单。
- 客户调研字段若与竞品功能冲突，以客户字段优先；竞品只补页面流程和管理颗粒度。
