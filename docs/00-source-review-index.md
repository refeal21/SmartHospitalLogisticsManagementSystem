## 对本项目的取舍

- V1 以 19-36 页后勤系统为主线，前 18 页作为底座和治理依据，37-47 页作为联动边界。
- 后勤四大板块必须落地到可执行页面、数据模型和状态流转，不能只做大屏卡片。
- 安全、应急、安保不在 V1 完整重建，但空间、设备、事件、工单、人员、告警数据必须预留联动接口。

## 公司规范提炼

- 必须有项目级约束文件，Codex 使用 `AGENTS.md`。
- 安全红线：客户真实数据、认证凭证、商业机密、服务器信息禁止发送给外部 AI 或提交仓库。
- 开发纪律：小步快跑、及时提交、范围可控、禁止无约束重构。
- 测试纪律：AI 生成测试需人工校验业务断言，必须覆盖关键边界与异常路径。
- 调试纪律：结构化描述问题，使用浏览器/Playwright/DevTools 类工具做可视化验证，复杂问题先列假设再修复。
