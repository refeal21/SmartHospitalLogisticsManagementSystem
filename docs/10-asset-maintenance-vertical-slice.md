# 资产台账与巡检保养纵切

## 目标

把“设备设施资产台账 + 巡检保养计划 + 异常转工单”做成可操作闭环，而不是只展示资产列表。V1 使用脱敏 mock 数据，保留 BIM 空间定位、责任班组、健康度、计划任务、检查结果、生命周期记录和异常工单链路。

## 来源约束

- 中科医信：资产分类、资产台账、资产维修管理、工作日历、巡检/保养、计划管理。
- PPT：基础运行保障、设备设施全生命周期管理、BIM 空间底座、监测预警与运维处置联动。
- 北建院：强电、暖通、给排水、医气、环境等真实系统分类、传感器、点位、字段和使用角色。

## 领域边界

- 资产台账：资产编码、系统分类、空间位置、BIM 构件、状态、责任班组、厂家型号、启用日期、维护策略、健康度、当前风险、来源标签。
- 巡检计划：计划编码、资产编码、任务类型、周期、下次到期时间、责任班组、检查模板、来源证据。
- 巡检任务：任务编号、计划、资产、状态、优先级、计划/到期时间、责任班组、检查结果、完成人、异常工单号。
- 生命周期：计划保养、告警联动、能耗复核、完成巡检、异常转工单等可审计事件。

## API 合约

- `GET /api/operations/asset-maintenance-board`
  - 返回资产台账、保养计划、到期任务、生命周期摘要、来源证据和 KPI。
- `GET /api/operations/assets/{assetCode}/maintenance`
  - 返回单资产详情、关联计划、任务、生命周期和来源证据。
- `POST /api/operations/maintenance-tasks/{taskNo}/complete`
  - 提交检查结果。
  - 正常结果关闭任务。
  - 异常结果可生成后续维修工单，任务状态变为 `ConvertedToWorkOrder`。
  - 不存在的任务返回 404，已关闭任务重复提交返回 400。

## 状态规则

- `Planned / Due / Overdue`：可执行巡检或保养。
- `Completed`：正常完成，写入生命周期记录。
- `RequiresRepair`：异常但暂不转工单，等待人工处理。
- `ConvertedToWorkOrder`：异常并生成后续维修工单，进入一站式服务闭环。

## 前端验收

- 页面包含“资产台账与巡检保养”“设备设施台账”“巡检任务”“生命周期记录”。
- 点击资产能看到资产编码、BIM 构件、空间位置、维护策略和风险。
- 点击“异常完成并转工单”后显示 `已转工单` 和 `WO-MT-*` 工单号。
- 移动端不因资产台账区域产生横向溢出。
