# 中科医信竞品功能矩阵（脱敏摘要）

## 资料边界

来源为本地 XMind《中科医信后勤一体化管理平台.xmind》。本文只沉淀模块名称、功能颗粒度和对本项目的参考映射，不复制品牌化表述、采购原文、交付承诺或专有文案。

## 功能矩阵

| 序号 | 竞品模块 | 功能颗粒度 | 本项目采用方式 |
| --- | --- | --- | --- |
| 1 | 智慧医院运行保障系统基础服务模块 | 个人工作台、用户管理、角色权限、统一登录、工单管理、消息推送、数据安全、日志、人员、空间、组织、资产、岗位 | V1 首批建设基础平台、工作台、权限、日志和主数据 |
| 2 | 可视化数据驾驶舱管理系统 | 综合服务、品质管理、设备安全、能耗管理 | 作为运营首页和管理驾驶舱指标来源 |
| 3 | 智能移动应用终端系统 | 配置注册、消息、一站式服务、统一报警、设备运维、机电安全、统计分析、职工服务、个人信息维护 | V1 先做响应式 Web/PWA 信息架构，后续扩展 App |
| 4 | 智能基础运行资产台账管理系统 | 资产分类、资产台账、资产维修 | V1 建资产台账和维修记录，关联 BIM 空间与工单 |
| 5 | 基础运行设备设施使用运维系统 | 工作日历、消息、报修、巡检/保养、计划 | V1 做计划工单、巡检保养和消息待办 |
| 6 | 后勤供料配件耗材库智能管理系统 | 基础信息、仓库、采购决策、耗材精细化、统计分析 | 与工单备件消耗联动，V1 保留备件库存和出入库模型 |
| 7 | 智慧电梯运行监测管理系统 | 运行实时监测、报警、可视报警求助、统计分析 | 电梯作为专项监测系统，告警接入预警池和工单 |
| 8 | 医用气体预警监测管理系统 | 氧气、压缩空气、负压真空、特殊气体汇流排、报警接收与处置 | 医气按子系统建监测点、阈值和处置流程 |
| 9 | 供配电监测管理系统 | 运行总览、电力监测、数据报表 | 与北建院强电字段合并为供配电专项 |
| 10 | 给排水监测管理系统 | 运行总览、运行监测、APP远程监控 | 与北建院给排水字段合并为给排水专项 |
| 11 | 冷热站监测管理系统 | 运行总览、运行监测、App远程监控 | 与暖通空调冷源和热源字段合并为冷热站专项 |
| 12 | 环境质量监测管理系统 | 运行总览、运行监测、监测分区配置、环境区间配置 | 支撑室内空气质量、CO2、温湿度和分区阈值 |
| 13 | 污水站监测管理系统 | 实时监测、报警处理 | 与给排水/医疗废水数据形成污水站专项 |
| 14 | 智能一站式服务综合管理系统 | 调度中心、维修管理、移动维修、移动报修、工程仓库、报表、大屏 | V1 的核心业务闭环，先实现报修-派单-接单-完工-验收-评价 |
| 15 | 智慧保洁服务管理系统 | 工作日历、任务概览、计划、任务、应急保洁、统计分析 | 作为后勤服务子域，优先纳入一站式任务和质量考核 |
| 16 | 医疗废弃物综合管理系统 | 收集总览、可视化大屏、全生命周期监管、暂存站监管、扎带管理、统计分析 | 环境监管重点场景，V1 做医废风险、暂存间、处置工单和统计 |
| 17 | 可视化空间运维管理系统 | 建筑空间、空间平面图、空间使用、空间统计、空间租赁 | 与 BIM 空间底座融合，支撑设备/告警/工单定位 |
| 18 | 综合能耗智能监管系统 | 用能总览、实时监控、告警、用能分析、报表、成本、配置 | 能耗纳入综合管理与专项监测，关联强电、冷热站、水系统 |
| 19 | 后勤业务集成管理系统 | 业务集成、数据联动、统一入口 | 作为 IntegrationHub 目标，不在 V1 重做所有外部系统 |
| 20 | 服务品质集成管理系统 | 服务品质、考核评价、报告分析 | 与满意度、SLA、质量标准、合同考核形成闭环 |

## 对产品设计的约束

- 竞品功能用于补齐“页面、流程、操作对象、统计维度”的成熟颗粒度。
- 竞品模块不能替代客户调研字段；同一功能同时出现时，客户字段优先，竞品流程补齐。
- V1 不做空洞驾驶舱，任何大屏指标必须能追溯到工单、资产、点位、能耗或质量记录。
