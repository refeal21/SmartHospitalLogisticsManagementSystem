# 客户物联数据接入模型纵切

## 目标

把北建院客户调研中的系统分类、传感器、安装位置、可采集字段、希望采集字段、角色和使用端沉淀成脱敏的物联点位目录。V1 不接真实设备协议，只建立可验证的数据模型、阈值规则、读数接入和风险判定。

## 来源约束

- 北建院：强电、暖通空调、给排水、医用气体、环境质量、污水站等真实客户系统和字段。
- 中科医信：供配电、医气、给排水、冷热站、环境质量、污水站等成熟专项功能颗粒度。
- PPT：BIM 智慧运维集成边界、IoT 采集、告警预警、处置闭环和 BIM 空间定位。

## 领域对象

- `IotSystemProfile`：客户系统分类、子系统、角色、使用端。
- `IotMonitoringPoint`：点位编码、名称、系统分类、BIM 位置、设备编码、协议适配器、指标字段、来源证据。
- `IotMetricDefinition`：指标编码、名称、单位、数据类型、客户来源字段。
- `TelemetryThresholdRule`：点位、指标、阈值方向、预警阈值、严重阈值、规则摘要。
- `TelemetryReading`：点位读数、采集时间、风险等级和规则命中说明。

## API 合约

- `GET /api/operations/iot-catalog`
  - 返回系统、点位、阈值规则和来源证据。
- `GET /api/operations/iot-points/{pointCode}`
  - 返回单点位详情、阈值规则、最近读数和来源证据。
- `POST /api/operations/iot-readings`
  - 接收入参点位、指标、数值、单位、采集时间。
  - 根据阈值规则返回 `Normal / Warning / Critical`。
  - 未知点位返回 404；未知指标返回 400。

## V1 覆盖

- 强电：电压、电流、有功功率、功率因数、频率、电度、谐波。
- 暖通：供回水温、压力、流量、能耗。
- 给排水：压力、流量、液位、水质。
- 医气：氧气压力、流量、报警状态。
- 环境：CO2、温度、湿度。
- 污水：PH、COD、流量。

## 验收

- 后端测试覆盖目录、点位详情、阈值判定、读数入库、404 和 400。
- 前端显示“客户物联点位接入”“点位目录”“时序字段”“阈值与读数”。
- 点击医气点位能看到 `BIM-IPD-F8-WARD`、氧气压力字段和来源证据。
- 模拟异常读数后显示严重风险。
