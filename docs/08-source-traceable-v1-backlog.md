# 来源可追溯 V1 功能矩阵

## 来源优先级

1. 北建院客户调研数据：决定真实系统、点位、字段、角色和使用端。
2. 中科医信竞品功能树：决定成熟功能颗粒度、页面对象和流程环节。
3. PPT 顶层架构：决定业务域、建设目标、模块规模和 BIM 智慧运维定位。
4. AI 补充：只能补工程衔接、命名、实现方案和缺口说明，不能单独生成业务功能。

## 实施顺序

1. 基础平台与工作台：个人工作台、消息、待办、权限、登录日志。
2. 一站式服务与工单：报修、派单、接单、挂单、转单、完工、验收、评价、超时提醒。
3. 资产台账与巡检保养：设备设施、空间、岗位、人员、计划工单、巡检/保养。
4. 客户物联数据接入模型：强电、暖通、给排水、医气、环境、污水等监测点位和时序字段。
5. 专项系统：电梯、医气、供配电、给排水、冷热站、环境质量、污水站、医废、能耗。
6. 综合管理：合同、质量、考核、服务品质、报表和运营分析。

## 验收规则

- 每个 V1 功能必须至少有一个非 AI 来源标记。
- 页面、API 和测试中的功能名称必须能回到本矩阵。
- 后续出现新客户资料时，先更新脱敏目录和来源矩阵，再更新工程实现。
